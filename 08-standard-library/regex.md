# Regular Expressions

## 1. Component Map

### a. Main Classes

| Name | Description |
|---|---|
| `basic_regex` | Regular expression object. |
| `match_results` | Identifies one regular expression match, including all sub-expression matches. |
| `sub_match` | Identifies the sequence of characters matched by a sub-expression. |

### b. Algorithms

| Name | Description |
|---|---|
| `regex_match` | Attempts to match a regular expression to an entire character sequence. |
| `regex_search` | Attempts to match a regular expression to any part of a character sequence. |
| `regex_replace` | Replaces occurrences of a regular expression with formatted replacement text. |

### c. Iterator

| Name | Description |
|---|---|
| `regex_iterator` | Iterates through all regex matches within a character sequence. |
| `regex_token_iterator` | Iterates through the specified sub-expressions within all regex matches in a given string, or through unmatched substrings. |

### d. Exception

| Name | Description |
|---|---|
| `regex_error` | Reports errors generated by the regular expressions library. |

### e. Traits

| Name | Description |
|---|---|
| `regex_traits` | Provides metainformation about a character type, required by the regex library. |

### f. Constants

| Name | Description |
|---|---|
| `syntax_option_type` | General options controlling regex behavior. |
| `match_flag_type` | Options specific to matching. |
| `error_type` | Describes different types of matching errors. |
